# Гармония · Кухни на заказ

Одностраничная демонстрационная концепция для салона кухонь на заказ. Сайт состоит из HTML, CSS, JavaScript и локальных ресурсов. Откройте `index.html` в браузере. Для карты и Telegram нужен интернет.

## Структура

| Файл или папка | Назначение |
| --- | --- |
| `index.html` | Единственная страница, в корне сайта |
| `styles.css` | Сетка, типографика, адаптация и анимации |
| `script.js` | Меню, галерея, фактуры и локальный черновик |
| `assets/` | WebP, SVG, локальные шрифты, стили и лицензии шрифтов |
| `.nojekyll` | Пустой файл для публикации статики без обработки Jekyll |
| `.gitignore` | Локальные настройки, секреты, временные и системные файлы |

## Публикация через GitHub Desktop

1. Войдите в GitHub Desktop под аккаунтом `kirill2k10`. Выберите **File → Add local repository** и укажите папку `work/harmoniya-kitchens-demo`. Убедитесь, что выбрана ветка `main`. [Добавление локального репозитория](https://docs.github.com/en/desktop/adding-and-cloning-repositories/adding-a-repository-from-your-local-computer-to-github-desktop)
2. Для нового репозитория нажмите **Publish repository**, укажите имя `harmoniya-kitchens-demo` и выберите публичную видимость для GitHub Free. Если репозиторий с таким именем уже существует, сначала проверьте его историю и подключите существующий репозиторий. [Публикация проекта через GitHub Desktop](https://docs.github.com/en/desktop/adding-and-cloning-repositories/adding-an-existing-project-to-github-using-github-desktop)
3. На GitHub откройте **Settings → Pages**. В разделе **Build and deployment** выберите **Deploy from a branch**, ветку **main** и папку **/ (root)**. Нажмите **Save**. [Настройка источника GitHub Pages](https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site)
4. После успешного развёртывания откройте [адрес сайта](https://kirill2k10.github.io/harmoniya-kitchens-demo/). Страница содержит `noindex, nofollow`. Доступ к публичному сайту по ссылке сохраняется.

Для обновления отредактируйте файлы, проверьте сайт в браузере, создайте коммит через **Commit to main** в GitHub Desktop и нажмите **Push origin**. Проверьте результат развёртывания в разделе **Actions** репозитория.

## Данные и изображения

- [Карточка салона](https://kuhni-garmonija.clients.site/) подтверждает направление «кухни на заказ», адрес Санкт-Петербург, Бухарестская ул., 33к1, телефон +7 950 000-21-88 и [контакт в Telegram](https://telegram.me/%2B79500002188). [Ссылка на карту](https://yandex.ru/maps/org/1324056763) взята из карточки.
- Интерьерные изображения для публикации созданы встроенным инструментом ImageGen по текстовым описаниям и подписаны как демонстрационные визуализации. В `assets/` сохранены `hero.webp`, `hero-small.webp` и `gallery-1.webp`–`gallery-3.webp`. Темы кадров — тёмно-зелёная кухня с бронзовым светом и круглым столом, пудровая кухня с рифлёными шкафами, оливковые рамочные фасады и светлая кухня с островом. Для всех кадров использован запрос на фотореалистичную интерьерную съёмку без людей, текста и логотипов.
- Графический знак, чертёж и три доски фактур сделаны для демонстрации. Доски иллюстрируют сочетания цветов и поверхностей. Этапы описывают примерный ход обсуждения и реализации.
- Форма предлагает указать размеры, планировку и пожелания. Черновик формируется в браузере без аналитики и отправки данных со страницы. После копирования посетитель сам открывает Telegram и решает, отправлять ли сообщение.

## UI UX Pro Max

Запрос на дизайн-систему предложил Scroll-Triggered Storytelling, просторную сетку, тёплую нейтральную палитру, контрастную типографику и поэтапное появление элементов. Адаптация под интерьерное ателье — молочный фон `#F3EFE7`, песочный `#E8DFD1`, графит `#252722` и бронза `#825537`. Ритм задают пронумерованные главы, широкие поля, чертёж на отдельном листе и чередование светлых и тёмных плоскостей. Формат «выразительная антиква + спокойный гротеск» реализован парой Oranienbaum и Golos Text с локальными файлами кириллицы. Лицензии SIL OFL находятся в `assets/`.

Поиск по UX и стеку уточнил видимый фокус, подписи к полям, сообщения у поля и поддержку `prefers-reduced-motion`. Для сенсорного ввода у интерактивных элементов есть явные кнопки.

## Проверка

Публикация проверена в Chromium через локальный HTTP-сервер с префиксом `/harmoniya-kitchens-demo/`. На ширинах 360, 390, 768, 1024 и 1440 px проверены загрузка ресурсов, навигация, галерея, доски фактур, форма, клавиатурное управление и отсутствие горизонтальной прокрутки. Анимации проверены в обычном режиме и с `prefers-reduced-motion`. Пути к CSS, JavaScript, WebP, SVG и шрифтам относительные. Для работы на GitHub Pages достаточно статических файлов в корне ветки.
